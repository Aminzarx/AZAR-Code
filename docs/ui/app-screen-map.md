# AZAR CRM — نقشه‌ی متنی صفحات (مختصات + دگمه‌ها + توضیحات)

این سند برای این نوشته شده که فقط با خواندن متن، بشود فهمید هر صفحه‌ی اپ
دقیقاً چه شکلی است — چه چیزی کجاست، هر دگمه چه برچسبی دارد و چه کاری
می‌کند، و رنگ/فاصله‌ها از کدام توکن طراحی می‌آیند. منبع مقادیر:
`docs/ui/design-tokens.json` + `docs/ui/design-system.md` (نسخه‌ی
Minimal Luxury v2.0.0).

**نکته‌ی مهم درباره‌ی «مختصات»**: چیدمان اپ با Flexbox است، نه
پیکسل‌های ثابت (استاندارد React Native) — پس مختصات Y زیر، تقریبی و بر
اساس یک صفحه‌ی مرجع **390×844dp** (اندازه‌ی متداول گوشی) محاسبه شده‌اند:
safe-area بالا ≈ ۴۷dp، پایین ≈ ۳۴dp. هر جا محتوا پویا/متغیر است (لیست‌ها،
متن‌های چندخطی)، به‌جای عدد قطعی نوشته شده «پویا». جهت افقی همیشه RTL
است: X="راست" یعنی شروعِ خط در چیدمان فارسی، X="چپ" یعنی انتهای خط.

رنگ‌های پرکاربرد (برای رجوع سریع، بقیه در design-tokens.json):
- `background/surface` = `#FAF8F5` (زمینه‌ی همه‌ی صفحات)
- `primary` = `#1C1B19` (متن پررنگ، دگمه‌ی اصلی)، `onPrimary` = `#FAF8F5`
- `secondary` (اکسنت طلایی/برنز) = `#8A6D3B`
- `tertiary` (اکسنت زمردی) = `#2F4F3E`
- `error` = `#B3261E`، `success` = `#2F6B4F`، `warning` = `#8A5A00`
- `surfaceContainerLowest` = `#FFFFFF` (زمینه‌ی کارت‌ها)
- `outlineVariant` = `#D8D2C4` (خط‌های نازک/حاشیه)

- چک‌باکس مربعی سمت چپ (۴۸×۴۸dp، گوشه‌ی متوسط): لمس مستقیم = انجام‌شده/نشده، تیک سفید روی زمینه‌ی `primary` وقتی انجام‌شده

### ۱۰.ب افزودن/ویرایش یادآوری
فرم در `FormScreenContainer`: «عنوان» (الزامی) → ردیف کنار‌هم «تاریخ» +
«زمان» (هر دو الزامی، FormRow) → «توضیحات» اختیاری → دگمه‌ی ثبت.

### ۱۰.ج جزئیات یادآوری
عنوان (`headlineMd`) → تاریخ/زمان فرمت‌شده → توضیحات (اگر باشد) →
دگمه‌ی «علامت‌گذاری به‌عنوان انجام‌شده/نشده» (`secondary`) → دگمه‌ی
«ویرایش» (`secondary`) → دگمه‌ی «حذف یادآوری» (`destructive`).

## ۱۱. پرونده‌ی ملکی (Property)

### ۱۱.الف افزودن/ویرایش ملک
فرم در `FormScreenContainer`:
«عنوان پرونده»* → «نوع ملک» (Autocomplete: آپارتمان/ویلایی/زمین/مغازه/دفتر)
→ «نوع معامله» (Autocomplete: فروش/اجاره/رهن و اجاره) → «شهر»*
(Autocomplete با پیشنهاد ~۸۰ شهر ایران، تایپ دستی هم مجاز) → «آدرس»* →
«قیمت (تومان)» (MoneyInput + چیپ‌های سریع) → ردیف کنار‌هم «متراژ» +
«تعداد اتاق» (FormRow) → «توضیحات» → دگمه‌ی ثبت.
(* = فیلد الزامی، ستاره‌ی قرمز کنار برچسب)

### ۱۱.ب جزئیات ملک
عنوان (`headlineMd`) → «شهر — آدرس» → نوع ملک، نوع معامله، قیمت،
متراژ، تعداد اتاق، توضیحات (هرکدام یک ردیف برچسب+مقدار) → دگمه‌ی
«ویرایش» → **بخش پیشنهادهای متقاضی مرتبط** (کارت‌های تطبیق، فقط برای
متقاضیان هم‌شهر).

---

## ۱۲. متقاضی (Applicant)

### ۱۲.الف افزودن/ویرایش متقاضی
فرم: «نام و نام خانوادگی»* → «شماره تماس»* → «نوع معامله مدنظر»
(Autocomplete: خرید/اجاره/رهن و اجاره) → «نوع ملک مدنظر» (Autocomplete)
→ «شهر»* (Autocomplete شهرها) → ردیف کنار‌هم «حداقل بودجه» + «حداکثر
بودجه» (هر دو MoneyInput، FormRow) → ردیف کنار‌هم «حداقل متراژ» +
«حداکثر متراژ» (FormRow) → «تعداد اتاق» → «توضیحات» → دگمه‌ی ثبت.
(فیلدهای ایمیل و حقیقی/حقوقی از این فرم حذف شده‌اند.)

### ۱۲.ب جزئیات متقاضی
نام کامل (`headlineMd`) → شماره تماس، شهر، نوع معامله مدنظر، نوع ملک
مدنظر، بودجه، متراژ، تعداد اتاق، توضیحات → دگمه‌ی «ویرایش» → دگمه‌ی
«حذف متقاضی» (`destructive`، تأیید با مودال) → **بخش پیشنهادهای ملک
مرتبط**.

## ۱۳. پروفایل / تنظیمات (Settings)

مسیر: `Settings` (از طریق هدر Dashboard یا تب «پروفایل»).
Container: `FormScreenContainer`.

| المان | ترتیب | توضیح |
|---|---|---|
| عنوان «تنظیمات» | ۱ | `headlineLgMobile` |
| کارت «شماره موبایل» | ۲ | برچسب + مقدار (از `UserRepository` خوانده می‌شود) |
| کارت «کد معرف شما» | ۳ | کد بزرگ (`headlineLgMobile`, letter-spacing) + **دگمه‌ی کپی** (آیکون `copy`, رنگ `primary`) کنارش + متن راهنما زیرش که بعد از کپی به «کد معرف کپی شد.» تغییر می‌کند |
| کارت «وضعیت نشست» | ۴ | نقطه‌ی سبز کوچک + متن «فعال» |
| **دگمه «خروج از حساب»** | ۵ (آخر) | `secondary`، تمام عرض — لمس آن **بلافاصله خارج نمی‌کند**، یک مودال تأیید باز می‌شود |

### مودال تأیید خروج
عنوان: «خروج از حساب». متن: «آیا مطمئن هستید که می‌خواهید از حساب
کاربری خود خارج شوید؟». دو دگمه: «انصراف» (می‌بندد، بدون تغییر) و
«خروج» (destructive، واقعاً خارج می‌کند و به Auth Stack برمی‌گردد).

## الگوهای مشترک در همه‌ی صفحات

- **حالت بارگذاری**: `LoadingIndicator` (چرخان، رنگ `secondary`) وسط
  صفحه یا وسط بخش، بدون درصد (indeterminate).
- **حالت خالی**: بج آیکون دایره‌ای (زمینه‌ی خاکستری‌روشن) + عنوان
  (`titleSm`) + توضیح (`bodySm`) + دگمه‌ی اختیاری، همیشه وسط‌چین.
- **حالت خطا**: همان قالب بالا با زمینه‌ی قرمزِ کم‌رنگ (`errorContainer`)
  و آیکون `alert`، به‌همراه دگمه‌ی «تلاش مجدد».
- **فیلد الزامی**: ستاره‌ی قرمز (`*`) کنار برچسب.
- **حداقل ناحیه‌ی لمسی**: هر دگمه/آیکون/ردیف قابل‌لمس حداقل ۴۸×۴۸dp،
  حتی اگر شکل بصری کوچک‌تر باشد.
